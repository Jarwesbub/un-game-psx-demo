**UnGame - PlayStation 1 Tech Demo**

A small PlayStation 1 homebrew tech demo inspired by the classic fixed camera angles from the original Resident Evil games.

This is just a fun project to experiment with PS1-style camera systems and room transitions. It's still very much a work in progress, so expect a few bugs here and there. Some known issues include:

Camera transitions don't always work as intended.
The player may walk sideways after leaving the cabin.

The project was made using the PSXSplash development tools:

https://psxsplash.github.io/
_______________________________________________________________________________

You can play the demo on a modded PlayStation 1 or in a PS1 emulator. The latest build can be downloaded [here](https://github.com/Jarwesbub/un-game-psx-demo/releases/latest).
